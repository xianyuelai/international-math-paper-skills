# Mathematical Referee Response

Turn each referee comment into a verifiable response and an exact manuscript change. The aim is clarity and mathematical accountability, not rhetorical victory.

## Workflow

1. Preserve the referee report verbatim in the working record. Number each distinct request, question, and objection.
2. For each item, classify it as a mathematical correctness issue, exposition ambiguity, literature/citation request, scope claim, formatting/compliance issue, or disagreement requiring evidence.
3. Locate the relevant theorem, proof step, definition, citation, equation, or page in the current manuscript.
4. Draft only one of these evidence-based responses:
   - made a specified correction;
   - added a specified proof or explanation;
   - narrowed a claim because the original scope was unsupported;
   - respectfully retained the text, with a precise mathematical reason and location;
   - needs further work before a defensible response.
5. Maintain a revision ledger with comment ID, source location, changed files, before/after claim impact, and verification needed. Recompile the revised manuscript and re-audit any changed proof.

## Rules

- Quote the comment briefly and accurately; do not paraphrase it into a weaker objection.
- Never state that an issue is fixed unless the corresponding edit and proof check exist.
- Do not claim that a result is “well known” unless an exact reference and applicable hypotheses are supplied.
- If an objection reveals a gap, say so internally and repair or narrow the manuscript; do not write evasive prose.
- Keep the response respectful, concise, and independently readable.

## Deliverables

Produce a point-by-point response letter and a separate revision ledger. Every response must name the manuscript location changed (section, theorem, equation, page, or line after final compilation).
